# ☕ Exercícios e Desafios de Lógica de Programação em Java

Repositório contendo uma coletânea de exercícios práticos e desafios de lógica de programação e algoritmos desenvolvidos em **Java**. O conteúdo abrange desde conceitos fundamentais de sintaxe e tipos primitivos até estruturas de controle, decisões condicionais e resolução de problemas práticos.

---

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Java (Java SE / JDK 17+)
- **Paradigma:** Estruturado e Orientado a Objetos
- **Ferramentas de Desenvolvimento recomendadas:** VS Code, IntelliJ IDEA, Eclipse ou NetBeans
- **Controle de Versão:** Git & GitHub

---

```text

```

---

## 🛠️ Conteúdos e Tópicos Abordados

- **Entrada e Saída de Dados:** Leitura interativa via console com `java.util.Scanner` e saída com `System.out.println`.
- **Formatação de Dados:** Utilização de `java.text.DecimalFormat` para porcentagens e casas decimais.
- **Tipos Primitivos e Variáveis:** Manipulação de `int`, `double`, `boolean` e referências como `String`.
- **Operadores Aritméticos e Lógicos:** Cálculos matemáticos, conversões e operadores relacionais.
- **Estruturas Condicionais:** Tomada de decisão com blocos `if`, `else if` e `else`.
- **Resolução de Problemas do Mundo Real:** Algoritmos para cálculo de consumo elétrico, regras de aprovação escolar, validações e cálculos comerciais.

## 💻 Pré-requisitos e Execução Local

### Pré-requisitos
- **Java Development Kit (JDK 17 ou superior)** instalado na máquina.
- Para verificar se o Java está instalado:
  ```bash
  java -version
  javac -version
  ```

### Como Executar os Exercícios

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Maria-Perrone/java-exercicios-algoritmos.git
   cd java-exercicios-algoritmos
   ```

2. **Compilar um arquivo específico:**
   ```bash
   javac desafio01.java
   ```

3. **Executar o programa compilado:**
   ```bash
   java desafio01
   ```
